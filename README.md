# Интерактивные семинары по молекулярной биологии

Кафедра биологии и генетики · Медицинский университет Петровского · курс «Молекулярная биология», 5–6 семестры.

- `index.html` — главная страница со списком семинаров.
- `seminar-7.html` — семинар 7 «Регуляция метаболизма и аутофагии» (версия 3.0, вариант для студентов).
- `seminar-8.html` — семинар 8 «Метаболические потоки, биосинтез и редокс-состояние» (версия 3.0, вариант для студентов).
- `seminar-9.html` — семинар 9 «Митохондрии как энергетический, сигнальный и генетический узел» (версия 3.0, вариант для студентов).
- `seminar-10.html` — семинар 10 «Стрессовые программы: интегрированный стрессовый ответ, UPR, KEAP1-NRF2 и HIF» (версия 1.0, вариант для студентов).

Учебные материалы. При использовании ссылка на кафедру обязательна.
