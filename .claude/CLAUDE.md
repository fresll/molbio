# Правила для сессий Claude в репозитории fresll/molbio (сайт курса «Молекулярная биология»)

Этот репозиторий публикуется на https://edu.mazunin.science через GitHub Pages сразу после push в `main`. Поэтому:

1. **Не пушить в `main` напрямую.** Работать в отдельной ветке (например `правки/<дата>-<тема>`). В `main` — только слиянием после явной команды автора в текущем чате («Да, опубликовать» или равнозначной). Разрешение на одну публикацию не распространяется на следующую.
2. **Сначала сохранение на Мак автора.** Перед слиянием выгрузите автору в чат (или приложите файлом) все изменённые файлы с SHA-256 и список «было → стало», чтобы они были сохранены на Маке в `Публикации/<дата>_<тема>/` инструментом `инструменты/safe_publish.py`. Облачная среда не видит Мак — не считайте, что копия там есть, пока автор не подтвердил.
3. Перед работой: `git fetch`; ветку начинать от актуального `main`; перед слиянием снова `git fetch` и убедиться, что `main` не ушёл вперёд.
4. После публикации: дождаться сборки Pages (при ошибке «Page build failed» — повторить сборку, не менять файлы), сверить живые страницы с коммитом побайтно (запросы с паузой ≥ 1 с; ответ короче 3000 байт — служебная страница, не содержимое).
5. Не менять страницы, о которых не просили. Версии, даты и README — только по поручению автора.
