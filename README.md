# Интерактивные семинары по молекулярной биологии

Кафедра биологии и генетики · Медицинский университет Петровского · курс «Молекулярная биология», 5–6 семестры.

- `index.html` — главная страница со списком семинаров.
- `seminar-5.html` — семинар 5 «Нуклеосомы, ремоделирование и гистоны» (версия 3.4, вариант для студентов).
- `seminar-5-route.html` — семинар 5: объяснения перед практикумом (версия 3.4); открывается по ссылкам из seminar-5.html, отдельной карточки на главной нет.
- `seminar-6.html` — семинар 6 «Метилирование ДНК, регуляторные элементы и память» (версия 3.7, вариант для студентов).
- `seminar-6-route.html` — семинар 6: объяснения перед практикумом (версия 3.7); открывается по ссылкам из seminar-6.html, отдельной карточки на главной нет.
- `seminar-7.html` — семинар 7 «Регуляция метаболизма и аутофагии» (версия 3.6, вариант для студентов).
- `seminar-8.html` — семинар 8 «Метаболические потоки, биосинтез и редокс-состояние» (версия 3.6, вариант для студентов).
- `seminar-9.html` — семинар 9 «Митохондрии как энергетический, сигнальный и генетический узел» (версия 3.6, вариант для студентов).
- `seminar-10.html` — семинар 10 «Стрессовые программы: интегрированный стрессовый ответ, UPR, KEAP1-NRF2 и HIF» (версия 3.6, вариант для студентов).

Порядок шагов сценария и вариантов ответа на страницах семинаров перемешивается при каждом открытии; добавка `?fixed` к адресу (например, `seminar-6.html?fixed`) даёт постоянный порядок, как в гиде для преподавателя, — так страницу открывают на проекторе.

Оформление — в цветах Медицинского университета Петровского (синий и красный из логотипа), с логотипом в шапке. Цвета схем, тексты и версии семинаров не менялись; классическое оформление возвращается удалением блока между метками `<!--brand-univ:start-->` и `<!--brand-univ:end-->` в каждом файле.

Статистика посещений — GoatCounter (без cookie, личные данные не собираются): один тег `<script>` в каждой странице, между метками `<!--stats:start-->` и `<!--stats:end-->` перед `</body>`. При выкладке новой версии страницы блок нужно сохранять.

В подвале `index.html` между метками `<!--views:start-->` и `<!--views:end-->` стоит «глазок» с общим числом просмотров сайта (данные GoatCounter, показывается только если счётчик отвечает).

Учебные материалы. При использовании ссылка на кафедру обязательна.
